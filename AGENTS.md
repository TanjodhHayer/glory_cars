# Glory Auto Hub public website

This repository contains the public marketing site. Shop authentication, onboarding, billing, and the mobile API belong to the separate glorycars-loan project at portal.gloryautohub.ca.
Do not implement a second authentication system or move the portal domain when changing the public site.
Do not publish guaranteed approval, rates, trial activation, or subscription prices without verified product support.
Run npm run lint, npm test, and npm run build after relevant changes.
